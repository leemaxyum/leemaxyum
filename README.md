## ~/featured

### Fleavo / TPLAYTV — a shared screen, powered by phones

A TV-first real-time room platform: a host opens a room and phones join as players, controllers, and study participants.

**Focus:** room lifecycle · reconnection · state synchronization · multi-device UI  
**Stack:** Node.js · TypeScript · Socket.IO · Vite

[Repository →](https://github.com/leemaxyum/TPLAYTV)

---

### Forest Quest — action-platformer systems

A browser action-platformer with distinct stage archetypes, vertical routes, combat gates, diving enemies, upgrades, and boss-finishers.

**Focus:** movement feel · encounter design · game-state loops · effects  
**Stack:** JavaScript · Phaser 3 · HTML5 Canvas

[Repository →](https://github.com/leemaxyum/Forest-Quest)

---

### Phantom AI — AI application engineering

A chat application exploring streaming responses, conversation state, Markdown/code rendering, browser speech, and server-side API-key boundaries.

**Focus:** async UX · persistence · server boundaries · product polish  
**Stack:** React · TypeScript · Vite · Gemini · Netlify Functions

[Repository →](https://github.com/leemaxyum/phantom-ai)
